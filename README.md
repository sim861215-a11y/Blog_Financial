# 기업분석 보고서 자동화 시스템

일반 투자자를 위한 기업분석 보고서를 자동 생성하는 단일 파일 웹 앱입니다.  
DART에서 재무데이터를 조회하고, Gemini로 뉴스를 검색하며, Claude가 보고서 초안을 작성합니다.  
보고서를 작성할수록 문체가 자동으로 학습·개선됩니다.

---

## 보고서 구성

| 섹션 | 내용 | 특이사항 |
|---|---|---|
| I. 기업 개요 | 회사 소개 (일반인 눈높이) | 전문용어 쉬운 말 병기 |
| II. 사업 현황 및 시장 환경 | 시장 전망 차트 + 경쟁력 | SVG 막대차트 자동 생성 |
| III. 최근 주요 이슈 | 주목도 1위 이슈 1건 | 중복·저중요도면 섹션 생략 |
| IV. 재무 현황 분석 | 수익성·현금흐름·재무안전성 + 소결론 | 5개년 + 최근 분기 |
| V. 기업가치평가 | 유사상장기업 비교법 (EV/EBITDA·P/E·P/B) | 적정가치 자동 산정 |
| VI. 주요 리스크 요인 | 사업·재무·외부환경 리스크 | 영향도(상/중/하) 표기 |
| VII. 종합 의견 | 긍·부정 요인 + 최종 판단 + 모니터링 포인트 | |

## 시작하기

### 1. API 키 발급

| API | 용도 | 발급처 | 요금 |
|---|---|---|---|
| DART Open API | 재무제표 자동 조회 | [opendart.fss.or.kr](https://opendart.fss.or.kr) | 무료 |
| Google Gemini API | 뉴스 검색·요약 + 스타일 학습 | [aistudio.google.com](https://aistudio.google.com/app/apikey) | 무료 할당량 있음 |
| Anthropic Claude API | 보고서 초안 작성 (Sonnet 4) | [console.anthropic.com](https://console.anthropic.com) | 유료, 건당 약 $0.07 |

### 2. 로컬 실행 (권장)

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
# index.html을 브라우저에서 직접 열기
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

> 로컬 실행 시 CORS 프록시 설정 불필요합니다.

### 3. GitHub Pages 배포

1. `Settings → Pages → Source: Deploy from a branch → main / (root) → Save`
2. 배포 완료 후 `https://YOUR_USERNAME.github.io/YOUR_REPO/` 접속
3. DART API CORS 오류 발생 시: `⚙ API 설정 → CORS 프록시 URL`에 `https://corsproxy.io/?` 입력

## 5단계 사용법

```
[1단계] 기업 입력
  기업명 또는 종목코드 → DART 자동 검색
  DART 키 없으면 직접 입력 가능

[2단계] 재무정보
  ├── 재무상태표·손익계산서·현금흐름표: 5개년 + 최근 분기 자동 조회
  ├── 주요 지표: 부채비율·ROE·영업이익률 등 자동 계산
  ├── 모든 셀 직접 수정 가능
  └── 유사상장기업 탭: EV/EBITDA·P/E·P/B 배수 자동 계산

[3단계] 초안 작성
  ├── 뉴스 검색: Gemini가 최근 3개월 기사 검색
  │   └── 주목도 1위 이슈 1건만 선정, 중복·저중요도면 섹션 자동 생략
  └── AI 초안 생성: Claude가 시장 데이터 검색 포함 전체 보고서 작성
      └── 3→4단계 이동 시 스타일 자동 학습 (백그라운드)

[4단계] 이미지 삽입
  차트·캡처 이미지 업로드 → 에디터에 삽입

[5단계] HTML 출력
  티스토리 HTML 편집기에 붙여넣기 가능한 코드 출력
  미리보기·다운로드 지원
```

## 핵심 기능

### 시장 데이터 SVG 차트 자동 생성
Claude가 web_search로 업종 시장 규모·성장률을 직접 검색해 보고서 스타일의 SVG 막대차트를 생성합니다.
- 실적 막대: 검정(`#111111`), 전망 막대: 회색(`#aaaaaa`)
- 전망 구간 배경 음영, 전망 연도 `24F` 형식 표기

### 뉴스 이슈 자동 판단
Gemini가 조회수·시장 영향도 기준으로 가장 주목받는 이슈 1건만 선정합니다.
- 이전 보고서와 중복되거나 중요도가 낮으면 섹션 전체를 자동 생략
- 오류 시 3회 자동 재시도 (Exponential Backoff)

### 스타일 자기학습
3→4단계 이동 시 Gemini가 편집된 보고서에서 문체 패턴을 추출해 자동 누적합니다.
- 최대 20개 패턴 보관
- 다음 보고서 생성 시 Claude 프롬프트에 자동 반영
- `⚙ 설정 → 스타일 학습 데이터`에서 관리·내보내기·가져오기 가능

### 일반 투자자 눈높이 작성
- 전문용어에 즉시 쉬운 말 병기 (예: "EBITDA(영업 현금흐름에 가까운 지표)")
- 수치마다 "좋은 건지 나쁜 건지" 평가 한 줄 추가
- 기관 보고서 문체 배제, 읽기 쉬운 문장

## 분기별 업데이트 방법

```
1. 3단계 → 뉴스 검색 (자동으로 최근 3개월, 과거 이슈 중복 제외)
2. AI 초안 생성
3. 에디터에서 수정
4. 다음 → 클릭 시 스타일 자동 학습
5. 5단계에서 HTML 복사 → 티스토리 발행
```

뉴스 이슈 이력은 기업별로 분기별 최대 12분기 보관됩니다.

## 데이터 저장

| 데이터 | 저장소 | 유지 기간 |
|---|---|---|
| API 키 3종 | sessionStorage | 탭 닫으면 삭제 |
| 뉴스 이슈 이력 | localStorage | 기업별, 최대 12분기 |
| 스타일 패턴 | localStorage | 최대 20개, 영구 |
| 보고서 템플릿 | sessionStorage | 탭 닫으면 삭제 |

> API 키는 브라우저 내에만 저장되며 외부로 전송되지 않습니다.
