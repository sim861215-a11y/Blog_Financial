# 기업분석 시스템

DART 재무데이터 자동 조회 + Gemini 뉴스 검색 + Claude AI 보고서 작성을 하나의 HTML 파일로 구현한 기업분석 자동화 도구입니다.

---

## 보고서 유형

### 📝 블로그용
일반 투자자 대상 · 전문용어 쉬운 말 병기 · 시장 데이터 SVG 차트 자동 생성

### 🔍 심사용
기관 심사역 대상 · 전문 문체 · 경쟁사 비교표 · 딥한 재무/밸류에이션 분석

---

## 시작하기

### API 키 발급

| API | 용도 | 발급처 | 요금 |
|---|---|---|---|
| DART Open API | 재무제표 자동 조회 | [opendart.fss.or.kr](https://opendart.fss.or.kr) | 무료 |
| Google Gemini API | 뉴스 검색 + 스타일 학습 | [aistudio.google.com](https://aistudio.google.com/app/apikey) | 무료 할당량 |
| Anthropic Claude API | 보고서 초안 + 종목코드 조회 | [console.anthropic.com](https://console.anthropic.com) | 유료 (~$0.07/건) |

> 우측 상단 ⚙ 버튼 → API 키 입력 → 저장 (이후 영구 보관)

### 로컬 실행

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
open index.html   # macOS
```

로컬 실행 시 CORS 프록시 불필요합니다.

### GitHub Pages 배포

1. `Settings → Pages → Source: main / (root) → Save`
2. DART 조회 오류 시: ⚙ 설정 → CORS 프록시 URL → `https://corsproxy.io/?` 입력

## 5단계 워크플로

```
1단계  기업 입력
       기업명 타이핑 → 내장 DB 자동완성 (KOSPI·KOSDAQ 약 200종목)
       목록 없으면 수동 입력 / DART 키 있으면 corp_code 자동 보완

2단계  재무정보
       ├── 재무상태표·손익계산서·현금흐름표: 5개년 + 최근 분기 자동 조회
       ├── 주요 지표: 부채비율·ROE·영업이익률 등 자동 계산
       ├── 모든 셀 직접 수정 가능
       └── 유사상장기업 탭: EV/EBITDA·P/E·P/B 배수 자동 계산

3단계  초안 작성
       ├── 보고서 유형 선택: 📝 블로그용 / 🔍 심사용
       ├── 뉴스 검색: Gemini가 최근 3개월 기사 → 주목도 1위 이슈 1건
       │   (중복·저중요도 이슈는 섹션 자동 생략)
       └── AI 초안 생성:
           - 블로그용: Claude + web_search로 시장 데이터 검색 → SVG 차트 포함
           - 심사용: Claude가 딥한 기관 보고서 작성 (web_search 미사용)
       → 다음 단계 이동 시 스타일 자동 학습 (백그라운드)

4단계  이미지 삽입
       차트·캡처 이미지 업로드 → 에디터 삽입

5단계  HTML 출력
       티스토리 HTML 편집기 바로 붙여넣기용 코드 출력
       미리보기·다운로드 지원
```

## 주요 기능

### 종목코드 자동완성
KOSPI·KOSDAQ 약 200개 종목이 내장 DB로 제공됩니다. 기업명 타이핑 시 즉시 드롭다운 표시, 선택하면 종목코드·시장·업종 자동 입력. DB 기준일이 드롭다운 하단과 선택 카드에 표시됩니다.

**종목 추가 방법:** `stocks.xlsx` 수정 후 `index.html`의 `STOCK_DB` 배열에도 반영

### 스타일 자기학습
3→4단계 이동 시 Gemini가 편집된 보고서에서 문체 패턴을 자동 추출·누적합니다.
- 최대 20개 패턴 · 보고서 생성마다 자동 반영
- ⚙ 설정 → 스타일 학습 데이터: 목록 확인·개별 삭제·JSON 내보내기/가져오기

### 뉴스 이슈 자동 판단
- 최근 3개월 기사 중 조회수·시장 영향도 기준 1건만 선정
- 이전 보고서와 중복 또는 저중요도 → 섹션 통째 자동 생략
- 오류 시 3회 자동 재시도

### 접근 비밀번호
⚙ 설정 → 접근 비밀번호 설정 시 페이지 열 때 입력 필요. 같은 브라우저에서 한 번 인증하면 탭 닫기 전까지 유지.

## 파일 구성

```
/
├── index.html      ← 전체 앱 (단일 파일, 2,300+ 줄)
├── stocks.xlsx     ← 종목코드 DB (A접두사=상장, B접두사=비상장)
├── README.md
└── .gitignore
```

### stocks.xlsx 형식

| 행 | A열 | B열 |
|---|---|---|
| 1행 | 코드입력일자 | 2026-05-21 |
| 2행 | 코드 | 기업명 |
| 3행~ | A005930 | 삼성전자 |
| | B000001 | 비상장기업 예시 |

- 상장기업: `A` + 6자리 종목코드
- 비상장기업: `B` + 임의 코드
- HTML에서 실제 사용 시 A/B 접두사 자동 제거 → 숫자 코드만 사용

## 데이터 저장

| 데이터 | 저장소 | 유지 기간 |
|---|---|---|
| API 키 3종 | localStorage | 영구 |
| 비밀번호 인증 상태 | sessionStorage | 탭 닫으면 초기화 |
| 뉴스 이슈 이력 | localStorage | 기업별 최대 12분기 |
| 스타일 패턴 | localStorage | 최대 20개 영구 |
| 보고서 템플릿 | sessionStorage | 탭 닫으면 초기화 |

> API 키는 브라우저 내에만 저장되며 외부로 전송되지 않습니다.
